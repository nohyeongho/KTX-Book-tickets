# KTX 취소표 실시간 자동 예약 프로그램

파이썬(Python)과 Selenium을 활용하여 코레일 예매 사이트의 취소표(빈자리)를 실시간 모니터링하고, 좌석이 나오는 즉시 선점(예약)한 뒤 경보음을 울려주는 프로그램입니다.

---

## 🌟 핵심 특징 및 안전 설계

1. **개인정보 안전 (Zero Credential)**:
   - 프로그램 코드 내에 아이디/비밀번호를 입력하지 않습니다.
   - 크롬 브라우저가 열리면 사용자가 직접 간편 로그인(카카오, 네이버, 코레일톡 인증 등)을 진행하므로 계정 탈취 위험이 없습니다.
2. **결제 사고 원천 차단**:
   - 금융 인증이나 결제까지 무리하게 자동화하지 않고 **'좌석 선점(예약)'까지만 수행**합니다.
   - 코레일은 예약 완료 시 **10~20분의 결제 유예 시간**을 부여하므로, 예약 성공 알림(비프음)을 들은 뒤 스마트폰 '코레일톡' 앱에서 수동으로 안전하게 결제하시면 됩니다.
3. **스케줄 없음 자동 복구 (`ensure_train_list_loaded`)**:
   - 코레일 사이트 특성상 "해당 스케줄에 운행하는 열차가 없습니다."가 뜨더라도 프로그램이 즉각 **[더보기]** 버튼을 자동 클릭하여 열차 목록을 정상 복구합니다.
4. **실시간 제어 (일시정지 / 다시 시작)**:
   - 실행 중 언제든 키보드로 일시정지(`p`), 다시 시작(`Enter`), 프로그램 종료(`q`)가 가능합니다.

---

## ⌨️ 단축키 안내

- **`p` 키** : 모니터링 일시정지 (브라우저를 보거나 잠시 멈출 때)
- **`Enter` 키** : 일시정지 상태에서 다시 모니터링 시작
- **`q` 키** : 프로그램 안전하게 종료

---

## 🚀 사용 방법

### 1단계: 프로그램 실행
```bash
python ktx_macro.py
```

### 2단계: 브라우저 조작 및 매크로 시작
1. 크롬 창이 열리면 코레일에 **로그인**합니다.
2. 출발역, 도착역, 출발 날짜, 시간대를 선택하고 **[열차 조회]**를 눌러 **'열차 목록 화면'**을 띄웁니다.
3. 터미널 창으로 돌아와 **`Enter` 키**를 누르면 모니터링이 시작됩니다.

### 3단계: 예약 성공 및 결제
- 좌석이 확보되면 컴퓨터 스피커로 **"삐- 삐- 삐-" 강력한 비프음 알람**이 울립니다.
- 스마트폰의 **[코레일톡 앱] > [장바구니/예약내역]**에 들어가서 10~20분 유예 시간 내에 결제하시면 됩니다!
